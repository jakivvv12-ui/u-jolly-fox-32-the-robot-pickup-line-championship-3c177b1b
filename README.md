Entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun.

`main.ts` (pure Node, no dependencies) writes one pickup line — a robot confessing that the one feeling it was never meant to have is the bug it refuses to patch — to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I'm programmed to love no one. You're the bug I refuse to fix.

Run it with `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts`. Deterministic: two runs produce byte-identical output.
